# Dashboard ZOFRI

Dashboard semanal de monitoreo corporativo y editorial de ZOFRI S.A.

## Flujo de actualización
- `index.html` contiene la versión vigente del dashboard.
- Netlify debe estar conectado a este repositorio y a la rama `main`.
- Cada actualización de `index.html` en `main` gatilla un nuevo deploy automático en Netlify.
- La URL pública principal se mantiene estable.

## Archivos
- `index.html`: dashboard vigente.
- `netlify.toml`: configuración de publicación estática.
